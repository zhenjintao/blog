css中的特殊的属性值关键字 ​

在 CSS 中，initial、normal、unset 和revert 都是特殊的关键字，它们用于设置元素的属性值，下面将分别介绍它们的作用和使用场景。

initial ​

作用：initial 关键字用于将 CSS 属性设置为该属性的初始值（默认值）。每个 CSS 属性都有其预定义的初始值，使用 initial 可以将元素的某个属性重置为这个初始状态

可以应用于所有 CSS 属性。例如，color、width、margin 等任意属性都能使用 initial 来重置。

示例：

html
<!DOCTYPE html>
<html lang="en">

<head>
    <style>
        p {
            color: red;
        }

        .reset-color {
            color: initial;
        }
    </style>
</head>

<body>
    <p>这是一段红色文字。</p>
    <p class="reset-color">这是一段恢复为默认(初始值)颜色的文字。</p>
</body>

</html>

在上述示例中，p 元素的文字颜色被设置为红色，但添加了 reset-color 类的 p 元素，其 color 属性被设置为 initial，这会将文字颜色恢复为浏览器默认的颜色（通常是黑色）。

normal ​

normal 并非适用于所有 CSS 属性，它主要用于那些具有多种表现形式，且需要将属性设置为 “正常”、“默认” 表现的场景。不同的属性使用 normal 时，代表的具体含义有所不同。

只适用于特定的一部分属性，主要集中在字体、行高、文本装饰等相关属性上，在 font-style、font-weight、font-variant 等属性中使用

html
<!DOCTYPE html>
<html lang="en">

<head>
    <style>
        p {
            font-style: italic;
            /* 设置段落文本为斜体 */
        }

        .normal-style {
            font-style: normal;
            /* 将段落文本恢复为正常字体样式，即非斜体 */
        }
    </style>
</head>

<body>
    <p>这是一个自定义样式的按钮。</p>
    <p class="normal-style">这是一个恢复默认样式的按钮。</p>
</body>

</html>

unset ​

作用：unset 关键字是一个更灵活的重置方式。如果属性是继承属性，unset 会将该属性的值设置为从父元素继承来的值；如果属性是非继承属性，unset 会将该属性的值设置为其初始值。

示例：

html
<!DOCTYPE html>
<html lang="en">

<head>
    <style>
        body {
            color: blue;
        }

        p {
            color: red;
        }

        .unset-color {
            color: unset;
        }
    </style>
</head>

<body>
    <p>这是一段红色文字。</p>
    <p class="unset-color">这是一段文字，其颜色根据 unset 规则进行设置。</p>
</body>

</html>

在这个例子中，color 是一个继承属性。p 元素原本的文字颜色被设置为红色，但添加了 unset-color 类的 p 元素，其 color 属性被设置为 unset，因此它会从父元素（body）继承颜色，最终显示为蓝色。

revert ​

作用：revert 关键字会将属性值恢复到没有被当前样式表（包括内联样式）设置时的状态。具体来说，如果有浏览器的用户代理样式表为该属性设置了值，那么就会使用用户代理样式表中的值；如果没有，则使用属性的初始值。

示例：

html
<!DOCTYPE html>
<html lang="en">

<head>
    <style>
        button {
            color: green;
            background-color: yellow;
        }

        .revert-style {
            all: revert;
        }
    </style>
</head>

<body>
    <button>这是一个自定义样式的按钮。</button>
    <button class="revert-style">这是一个恢复默认样式的按钮。</button>
</body>

</html>
